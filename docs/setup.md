# MajibuAI — Setup Guide

## Prerequisites
- Android Studio
- JDK 17 (or project-compatible JDK)
- Android SDK
- Android phone or emulator
- Git

## 1. Clone the Repository

git clone https://github.com/valentineRutto/majibuai.git
cd majibuai

## 2. Checkout the Starter Branch

git switch 00-starter

## 3. Open in Android Studio

Open the project and allow Gradle to sync.

## 4. Configure Cloud AI

Follow the backend setup instructions.

Do not put API keys directly in the Android app.

## 5. Run the App

Select your device and click Run.

## 6. Verify Setup

You should see:
- Ask AI screen
- Question input field
- Simulated AI response

## Troubleshooting
- Gradle sync issues
- Emulator configuration
- Network permissions
- Missing model files
